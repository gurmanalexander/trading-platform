# tvx — заметки для работы над проектом

- Стек: Vue 3 + TypeScript + Vite, графики — lightweight-charts. Проверка: `npx vue-tsc --noEmit` и `npx vitest run`.
- Интерфейс на двух языках: ключ перевода — русская строка в `t('…')`, английский — в `src/i18n/en/*.ts`
  (тест `tests/i18n.test.ts` следит за полнотой).
- **Обучающее видео** (окно «Обучение», `public/help`) записывается сценарием: `scripts/tutorial/README.md`.
  Добавили или заметно поменяли что-то в интерфейсе — добавьте реплику и действие в `scripts/tutorial/scenes.mjs`
  на обоих языках и перезапишите видео. Вспомогательные скрипты для видео и картинок держите в репозитории,
  а не только в рабочей папке сессии: первая версия обзора делалась скриптами, которые потом пропали.
- **Журнал сделок** (`journal/`) и **расширение-мост** (`extension/`) — отдельные сборки в том же репозитории:
  `npm run build` собирает терминал, журнал (`dist/journal/`) и расширение в двух вариантах — для Chromium
  (`dist-extension/`) и Firefox (`dist-extension-firefox/`); архивы кладутся в `dist/journal/`. Историю с биржи
  грузит и хранит расширение (в фоне, по расписанию), журнал получает от него готовые сделки. Переводы журнала и моста — в `journal/src/i18n/en.ts` (тест `tests/journal-i18n.test.ts`).
  Ключи бирж живут только в расширении; в протокол моста (`journal/src/core/protocol.ts`) нельзя добавлять запросы,
  которые что-либо меняют на бирже или отдают ключи сайту.
- Настоящие биржи из облачной сессии недоступны (блокировка по региону). Мост проверяется на учебной бирже:
  `node scripts/e2e-bridge.mjs --sync` (расширение + журнал + синхронизация в Chromium), тесты — `tests/journal-bridge.test.ts`.
  Учебная биржа написана по документации, поэтому после правок клиентов бирж нужна проверка настоящим ключом.
  Firefox в контейнере нет: его сборка проверяется только тем, что собирается.
