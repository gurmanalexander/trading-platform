# Обучающее видео: как оно сделано и как его дорабатывать

Видео-обзор в окне «Обучение» (кнопка с шапочкой наверху, пункт «Обучение» в меню «Ещё» на телефоне)
записывается **автоматически**: сценарий открывает приложение в браузере, ведёт курсор и клавиатуру по главам,
пишет кадры, а по тем же отметкам времени — субтитры и оглавление. Записей две — русская и английская,
с одинаковыми действиями. Руками ничего не монтируется: поправили сценарий — перезаписали.

## Быстрый старт

```sh
node scripts/tutorial/record.mjs --script                    # 1. текст: SCENARIO.md и out/<lang>/lines.json
python3 scripts/tutorial/tts.py ru && python3 scripts/tutorial/tts.py en   # 2. озвучка изменённых реплик (по желанию)
node scripts/tutorial/record.mjs --until 4 --fast --shots    # 3. черновик первых глав: снимки в out/ru
node scripts/tutorial/record.mjs                             # 4. чистовая запись обоих языков → public/help
```

- `--lang ru|en` — один язык (по умолчанию оба), `--until N` — остановиться перед частью N+1,
  `--fast` — паузы вчетверо короче (только для проверки действий), `--shots` — снимок после каждой реплики,
  `--no-phone` — без части про телефон. Черновые прогоны (`--until`, `--fast`) пишут только в `scripts/tutorial/out/`
  и **никогда** не трогают `public/help`.
- Нужны: Node 22, Playwright с Chromium (берётся системный, в проект не ставится), ffmpeg/ffprobe; для озвучки —
  Python и `pip install edge-tts`.
- Чистовая запись идёт в реальном времени: ~15 минут на язык плюс сборка.

## Как устроен сценарий

```js
await d.chapter(6, ru('Рисование', 'Drawing'))           // заставка «Часть 6» + пункт оглавления
await d.say(
  ru('Русская реплика.', 'English line.'),                // субтитры (и озвучка) на языке записи
  async () => {                                           // что происходит на экране, пока идёт реплика
    await d.keys('Alt+h', 'Alt+H')                        // нажатие с подсказкой клавиш на экране
    await d.click(await inChart(d, 0, 0.62, 0.32))        // точка в окне 0: доли ширины и высоты области цены
  },
)
```

- Реплика длится столько, сколько звучит её озвучка (+0,35 с), а без озвучки — сколько нужно, чтобы прочитать
  субтитры (≈13,5 знака в секунду по-русски, 15 — по-английски). Если действия дольше — реплика ждёт действия.
  Поэтому действия раскладывают внутри `say`, а паузы между ними — `d.sleep(ms)`.
- Длинная реплика сама делится на субтитры по предложениям.
- Помощники режиссёра: `d.click(loc|{x,y}, fx, fy, { modifiers, button, clickCount })`, `d.hover`, `d.move(x, y, ms)`,
  `d.drag(from, to, ms)`, `d.dblclick`, `d.keys(combo, подпись)`, `d.type(text, delay)`, `d.wheel(dy, n)`,
  `d.clip(text)` — положить текст в буфер (как будто скопировали из заметок), `d.dialogs([...])` — ответы
  на `prompt/confirm`, `d.T('русская строка интерфейса')` — та же строка на языке записи (по словарю
  `src/i18n/en`), `d.L(ru(...))` — выбрать вариант по языку.
- Селекторы: по классам компонентов и по `title` через `d.T(...)` (`title(d, 'Настройки')`), чтобы один и тот же
  код работал на обоих языках. Порядковые — `:nth-match(.pane, 1)` (а не `>> nth=`, если дальше идёт CSS).
- Добавили в приложение что-то новое — добавьте реплику в нужную часть (или новую часть) на **обоих** языках,
  прогоните `--script`, затем черновик нужных частей с `--shots` и посмотрите снимки.

## Данные

Запись идёт на живых ценах. В среде записи фьючерсный адрес Binance и потоки WebSocket бывают недоступны, поэтому
`market.mjs` перенаправляет фьючерсный REST на официальный адрес рыночных данных `data-api.binance.vision` (спот;
цены почти те же), а поток котировок заменяет опросом REST в том же формате. Запросы идут из Node через прокси
окружения (`record.mjs` сам перезапускается с `NODE_USE_ENV_PROXY=1`). Синхронизация устройств в записи говорит
с «тихим» ретранслятором прямо в странице — данные никуда не уходят, а окно синхронизации показывает связь.
Открытый интерес на споте взять негде — индикатор OI в записи пустой, его не показываем.

Телефон пишется отдельным браузером (iPhone 13) после компьютера; ему передаётся всё сохранённое на компьютере,
как будто он подключился к синхронизации. Кадры телефона ставятся по центру кадра 1600×900.

## Озвучка

1. `node scripts/tutorial/record.mjs --script` — `out/<lang>/lines.json` с текстами и хешами реплик.
2. `python3 scripts/tutorial/tts.py ru` (и `en`) — mp3 в `audio/<lang>/`. Уже озвученные реплики не переделываются,
   после правки сценария озвучиваются только новые и изменённые фразы.
3. Запись подхватит звук сама: длительность реплик — по звуку, громкость ролика выравнивается (`loudnorm`).

Голоса: `ru-RU-DmitryNeural` (скорость +4%, как в первой версии) и `en-US-AndrewNeural`. Голос неверно читает
название или сокращение — добавьте замену в `PRONOUNCE` в `tts.py` (субтитры при этом не меняются).
Файлы озвучки стоит коммитить: тогда при следующей правке не нужно озвучивать всё заново.

## История

- **Первая версия (12.11.2026)**, только русская, 15 частей, 14:48. Писалась скриптами в рабочей папке сессии —
  в репозиторий они не попали, поэтому вторую версию пришлось собирать заново. Подход: сначала озвучка edge-tts
  (Dmitry, +4%), затем запись Playwright, где каждая сцена длится по своему звуку; для голоса — отдельный текст
  с «фонетикой» («ти-ви-икс», «Байнэнс»); точки на графике считались по ценам через `chartAt(i)` из приложения;
  сборка — ffmpeg, crf 21, звук с `loudnorm`.
- **Вторая версия (25.11.2026)**, русская и английская, 16 частей + телефон. Всё, что появилось после первой:
  первый запуск (язык, тема, пояс, биржа), английский интерфейс, таймер свечи и цвет цены, часовой пояс в углу
  графика, тонкие бары и линия цены, шрифты и размер позиции, магнит в три режима и перекрестие с магнитом,
  линейка (Alt+M, Shift+щелчок), рисование и линейка в панелях индикаторов, видимость рисунков по интервалам как
  в TradingView, переносимая панель рисунка, поле R/R и привязка стопа к тейку, объём позиции по депозиту, CDV
  и открытый интерес, «Поделиться списком», снимок в буфер, акции в отборе, полоса монет и колонка набок на телефоне.
  Сценарий и режиссёр — в этой папке. Записана без звука (пояснения — в субтитрах): edge-tts в среде записи
  был недоступен.

## Грабли

- **Не правьте `src/` во время записи**: dev-сервер Vite перезагрузит страницу, и сценарий упадёт посреди главы.
- Выпадающие меню (`Dropdown`) закрываются нажатием мимо, а не Escape: в сценарии это делает `esc(d)`.
- `page.mouse.click` не принимает клавиши-модификаторы — `d.click(..., { modifiers: ['Control'] })` зажимает их сам.
- Окна `prompt/confirm` в кадр не попадают — отвечайте на них заранее через `d.dialogs([...])` и проговаривайте
  в реплике, что происходит.
- В отборе и списках порядок монет зависит от рынка на момент записи — выбирайте строки по номеру, а не по тикеру,
  или проверяйте, что монета есть на споте Binance.
- Упало — смотрите `out/<lang>/error.png` (снимок в момент ошибки) и последние `shot-*.png`.
