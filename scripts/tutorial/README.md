# Обучающее видео

Видео-обзор в окне «Обучение» записывается автоматически: сценарий открывает приложение в браузере,
ведёт курсор и клавиатуру по главам, пишет кадры и по тем же отметкам времени — субтитры и оглавление.
Две записи — на русском и на английском — с одинаковыми действиями.

```sh
node scripts/tutorial/record.mjs                         # оба языка → public/help
node scripts/tutorial/record.mjs --lang en               # один язык
node scripts/tutorial/record.mjs --until 5 --fast --shots   # черновик первых глав со снимками, в scripts/tutorial/out
```

Нужны Playwright с Chromium и ffmpeg. Результат:

| язык | видео | субтитры | оглавление |
| --- | --- | --- | --- |
| ru | `public/help/tvx-obzor.mp4` | `tvx-obzor.vtt` | `chapters.json` |
| en | `public/help/tvx-overview.mp4` | `tvx-overview.vtt` | `chapters.en.json` |

- `scenes.mjs` — главы и реплики на двух языках. Строки интерфейса в селекторах — через `d.T('русская строка')`.
- `record.mjs` — режиссёр: курсор, щелчки, клавиши с подсказкой на экране, субтитры, сборка ролика.
- `market.mjs` — живые котировки: фьючерсы Binance берутся с официального адреса рыночных данных
  `data-api.binance.vision`, поток WebSocket заменён опросом REST (в среде записи биржевые потоки бывают недоступны).
- `overlay.mjs` — курсор, след щелчка, подсказка клавиш и заставки глав поверх приложения.

## Озвучка

Если положить звук реплик в `scripts/tutorial/audio/<lang>/<номер>.mp3` (или `.wav`), длительность каждой
реплики берётся по файлу, а звук ложится в видео. Номера и тексты реплик — в `scripts/tutorial/out/<lang>/lines.txt`
после любого прогона. Без файлов видео пишется без звука, пояснения — в субтитрах.
